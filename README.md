# Romantic Cyberpunk - Love Confession App

Uma aplicação web moderna, responsiva e romanticamente cyberpunk para fazer uma pergunta especial.

## ✨ Características

- **Design Moderno**: Cyberpunk romântico com neon e efeitos visuais impressionantes
- **Responsivo**: Funciona perfeitamente em desktop, tablet e mobile
- **Vue 3**: Framework JavaScript reativo e moderno
- **Animações Suaves**: Transições e efeitos visuais envolventes
- **Boas Práticas**: Código limpo, bem estruturado e documentado
- **Performance**: Otimizado para velocidade e eficiência

## 🚀 Como Começar

### Pré-requisitos
- Node.js 16+ 
- npm ou yarn

### Instalação

```bash
# Clone o repositório
git clone https://github.com/danyton/NCL.git
cd NCL

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

O aplicativo será aberto em `http://localhost:5173`

### Build para Produção

```bash
npm run build
```

Os arquivos prontos para produção estarão em `dist/`
